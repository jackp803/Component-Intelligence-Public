# Electrical Workspace implementation status

Branch: `gpt/electrical-design-core`

This branch introduces the Electrical Design Engine（電氣設計引擎）foundation and a first WPF Electrical Workspace（WPF 電氣工作區）.

The workspace exposes project snapshot save/load, Component Instance（元件實例）, Net（電氣網路）, Terminal Block / Connection Point / Shorting Jumper（端子台／接線點／短路片）, direct Wiring（配線）, Physical Layout（實體佈局）data entry, and Validation / Drawing Readiness（驗證／繪圖可用性）.

Drawing IR and AutoCAD Drawing Automation are intentionally excluded and remain the next independent function.
